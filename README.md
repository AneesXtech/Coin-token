# HouseFacts Token — Blockchain Real Estate

Institutional-grade property intelligence and decentralized verification. An 8-module sovereign digital infrastructure built on WebGL, Three.js, and GSAP.

## Features
- **Interactive 3D DNA Helix & Gold Coin**: Real-time procedural Three.js visualization with realistic PBR HDR environment reflections.
- **GSAP ScrollTrigger Pinned Narrative**: Smooth 8-phase scroll animation through the 8 platform modules.
- **Dedicated Contact Portal (`contact.html`)**: Complete inquiry dispatch system.
- **PHP Email & SMTP Backend (`contact.php`)**: Full support for native PHP `mail()` and direct authenticated SMTP (TLS/SSL) for WordPress / cPanel hosting, sending directly to `Alejom.prs@gmail.com`.
- **Newsletter Subscription**: Instant asynchronous footer subscription handler.
- **Floating Back-to-Top**: Smooth scrolling with dynamic fade-in.
- **Zero Framework Bloat**: Pure Vanilla HTML5, CSS3, and JavaScript.

## Deployment
Simply upload the contents of this repository to your web server (e.g., Apache, Nginx, or cPanel `public_html`).
